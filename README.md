# LinOps Academy 🎓
**An offline-first, terminal-based Linux Administration & Security Sandbox.**

## 🚀 Overview
Built for Hacktoberfest Bhopal, LinOps Academy solves a core problem for computer science students: practicing dangerous sysadmin and security tasks without the overhead of heavy Virtual Machines. It provides a safe, fully local environment to learn file permissions, network scanning, and vulnerability analysis.

## 🛠️ Core Modules
* **Interactive Education Sandbox:** Generates safe lab environments to quiz students on Linux octal permissions.
* **Network Port Scanner:** Multithreaded native bash scanner utilizing `/dev/tcp`.
* **Vulnerability Checker:** Offline CVE correlation engine (Zero API keys required).
* **Environment Integrity:** Automated health and baseline checks for student environments.
